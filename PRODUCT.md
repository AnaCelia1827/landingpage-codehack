# Code Hack

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
HTML, CSS e JavaScript estáticos. Escolha de implementação para este projeto inicial sem framework.

## Users
Jovens de 15 a 19 anos, incluindo ex-participantes do Code Club e estudantes da rede pública de São Paulo.

## Product Purpose
Divulgar o hackathon piloto do Code Club, explicar o desafio e orientar jovens sobre participação, preparação e entregas.

## Operating Context
Semana de capacitação e desenvolvimento online, seguida de final presencial no Inteli. Equipes de 3 a 6 participantes. Mentorias, protótipo ou implementação, documentação, repositório GitHub e pitch.

## Capabilities and Constraints
Datas, formulário, endereço operacional, credenciamento, alimentação e materiais ainda não foram fornecidos. A página deve sinalizar esses dados como pendentes. IBM foi indicada pelo usuário como parceira.

## Brand Commitments
Nome Code Hack e organização Code Club. Referências visuais enviadas pelo usuário combinam cores fortes, formas orgânicas, mosaicos e elementos de jogos. Guia visual enviado indica verde, roxo, azul escuro e fundo claro.

## Evidence on Hand
Regulamento interno e TAP fornecidos na conversa. Não foram fornecidos fotografias originais, logotipos em arquivo, datas ou URL de inscrição.

## Product Principles
- Explicar o desafio e o caminho de participação rapidamente.
- Mostrar informação prática com honestidade sobre dados pendentes.
- Manter uma linguagem acessível a jovens sem perder precisão nas regras.
